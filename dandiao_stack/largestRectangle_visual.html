💡 核心思路

对于每一根柱子，以它的高度能形成的最大矩形，其左右边界分别是左右两边第一个比它矮的柱子。

单调递增栈的作用：栈中柱子高度递增，当遇到一个更矮的柱子时，栈顶柱子的「右边界」就确定了。

⏱ 时间 O(n) 📦 空间 O(n)

📋 算法步骤

  1. 遍历每根柱子 + 末尾哨兵 0
  2. 当栈非空 且 当前高度 < 栈顶高度时：
    弹出栈顶，以该高度计算矩形
  3. 矩形高度 = 弹出柱子的高度
  4. 矩形宽度 = 当前索引 − 新栈顶索引 − 1
  5. 更新最大面积
  6. 将当前索引入栈
🔑 关键技巧：末尾哨兵 0 确保遍历结束后所有柱子都从栈中弹出并计算面积，无需额外处理剩余元素。
