LeetCode 42 · Two Pointers

接雨水

左右双指针相向而行，维护 left_max 与 right_max。每轮处理当前柱高较矮的一侧：若它低于该侧已知最高边界就累加积水，否则更新边界。一趟扫描即可得到总水量。

时间 O(n) 空间 O(1) 策略 双指针 + 边界最大值

算法原理 Why it works

01 积水条件

位置 i 能积多少水，取决于它左右两侧最高柱子的较小值减去自身高度。

max_left(i) = max(height[0..i])
max_right(i) = max(height[i..n-1])
water[i] = min(max_left(i), max_right(i)) - height[i]

公式中的 max_left(i) / max_right(i) 是位置 i 两侧（含自身）的最高柱；代码中的 left_max / right_max 是扫描过程中维护的已知边界。

02 双指针策略
  1. 指针从最左、最右两端开始。
  2. 比较 height[left] 与 height[right]。
  3. 若左边更矮则处理 left，否则处理 right；两边相等时任选一侧都正确，本演示选择右侧。
  4. 若当前柱达到该侧最高值就更新 max，否则累加 max - 当前柱高。
  5. 处理完后将该侧指针向内移动。
  6. 两指针相遇时结束；相遇柱不会再产生积水。
核心洞察
指针只会在另一侧已有足够高边界时向内移动，因此始终保持一个关键条件：处理左侧时，当前右边界不低于 left_max；处理右侧时则相反。于是当 height[left] < height[right] 时，left 处的水位只受 left_max 限制：若 height[left] ≥ left_max 就更新边界，否则积水 left_max - height[left]。右侧情况完全对称。
03 代码执行位置
1left, right = 0, n - 1
2left_max = right_max = 0
3ans = 0
4while left < right:
5 if height[left] < height[right]:
6 if height[left] >= left_max:
7 left_max = height[left]
8 else: ans += left_max
- height[left]
9 left += 1
10 else: # 包含两端相等
11 if height[right] >= right_max:
12 right_max = height[right]
13 else: ans += right_max
- height[right]
14 right -= 1
15return ans
