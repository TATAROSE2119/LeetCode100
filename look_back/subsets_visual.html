LeetCode 78 · Backtracking

子集

对每个元素做出"选 / 不选"的二元决策，用深度优先搜索遍历整棵决策树，在叶子节点收集所有子集。

时间 O(n·2ⁿ) 辅助空间 O(n) 策略 回溯 + DFS

算法原理 Why it works

01 问题本质

给定 n 个不同元素的数组，求所有子集（幂集）。每个元素有选和不选两种可能，共 2ⁿ 个子集。

02 回溯策略
  1. 从索引 0 开始，维护当前路径 curr。
  2. 每次调用 dfs(i) 都压入一个栈帧；函数 return 时弹出该帧。
  3. 对 nums[i]：选它（加入 curr），递归到 i+1。
  4. 子调用返回后回溯：撤销选择，再走“不选”分支。
  5. 当 i == n 时到达叶子，保存 curr 的副本。
  6. DFS 遍历完所有可能的决策组合。
核心洞察
这是一棵完整的二叉决策树：左分支代表“选”，右分支代表“不选”。每条根到叶子的路径唯一对应一个子集，所以叶子总数为 2ⁿ，既不会遗漏，也不会重复。curr 是所有栈帧共享的可变路径；只有加入结果时才复制。

6 DFS(index + 1)
7 path.REMOVE_LAST()
8 // 不选择 nums[index]
