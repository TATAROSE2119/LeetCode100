💡 核心思路：双指针

指针 i：遍历整个数组。

指针 j：指向「下一个非零元素应该放置的位置」。

每当 i 遇到非零元素，就与 j 处元素交换，然后 j 前进。

最终：[0, j) 全是非零，[j, n) 全是零。

⏱ 时间 O(n) 📦 空间 O(1)

📋 算法步骤

  1. 初始化 j = 0
  2. i 从 0 遍历到 n−1：
  3. 若 nums[i] ≠ 0：
    交换 nums[i] 与 nums[j]
    j++
  4. 若 nums[i] = 0：
    跳过，i 继续前进
🔑 关键洞察：j 始终 ≤ i，j 左侧全是已处理的非零元素，j 到 i 之间全是零。一次遍历即可完成。
